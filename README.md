# Qwythos Local LLM

This folder defines steps for running Qwythos locally. Assumes you have several precursor Python modules and additional prerequirements installed

## Requirements

* Docker
* Python 3
* LM Studio


### Python Modules
* Pytorch (torch)
* Streamlit (Streamlit)
* Transformers (transformers)
* Pillow (PIL)

## LLM Requirements 

Download empero-ai/Qwythos-9B-Claude-Mythos-5-1M HuggingFace from https://huggingface.co/empero-ai/Qwythos-9B-Claude-Mythos-5-1M/tree/main
